# React Code 

This repo contains React code that is in the software engineering class. It covers components, React bootstrap, routers, lotties, and the use of zapier.

* javascript - provides an overview of JavaScript including objects, classes, and lambdas
* firstapp - presents the sample create-react-app with a Tile component that showcases props (created with create-react-app)
* houseapp - showcases different class and function components and the use of state and state hooks (created with create-react-app)
* routerapp - showcases how to use router that enables navigation between different views of a single-page react app (created with create-react-app)
* todoapp - showcase a todo app. It uses class components (created with create-react-app)
